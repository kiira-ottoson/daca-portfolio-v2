# DACA Portfoolio
 
**Programm:** Data Analyst Career Accelerator (DACA)
**Osaleja:** Kiira Ottoson
**Algus:** 17.06.2026
 
### Kirjeldus
See repositoorium sisaldab minu DACA õppeprojekte ja portfoolio. Õpe toimus simulatsioonis, kus tegutsesin fiktiivse ettevõtte UrbanStyle.ltd andmeanalüütikuna ja lahendasin nende reaalseid andmeprobleeme.
 
### Kontekst
UrbanStyle.ltd on fiktiivne Eesti moebränd, mis asutati 2020. aastal. Ettevõtte käive on ~3M€ (2024). Ettevõttel on kauplused Tallinnas, Tartus ja Pärnus ning lisaks veebipood.  Viimastel aastatel on ettevõte kiiresti kasvanud, mis on toonud kaasa väljakutseid andmete haldamises.

### Probleem
Ettevõtte andmeid hallati seni Excelis, kuid kiire kasv muutis selle lahenduse ebaefektiivseks. Mitme töötaja samaaegne töö on põhjustanud versioonide segadust, andmete dubleerimist ja ebajärjekindlust. Seetõttu on ettevõte alustanud üleminekut PostgreSQL andmebaasile, et parandada andmete kvaliteeti ja toetada andmepõhiseid äriotsuseid.

### Projekti eesmärk
Eesmärk on liikuda samm-sammult ebausaldusväärsetest algandmetest puhastatud, analüüsitud ja usaldusväärsete andmeteni, mille põhjal saab teha teadlikke juhtimisotsuseid. Projekti lõppeesmärk on koostada esitlusvalmis analüüsid ja visualiseeritud ülevaated juhtkonnale ja investoritele.
